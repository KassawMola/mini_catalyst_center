# mini_catalyst_center

Static GitHub Pages demo inspired by the MINI Catalyst Center operations portal.

This repository is demo-safe:

- No organization-specific names.
- No real branch names or production site names.
- No production IP addresses.
- Demo access is created by the visitor in the browser.
- Demo addressing only: `192.168.1.1`, `192.168.1.2`, `192.168.1.3`.

## GitHub Pages

Publish from:

```text
Branch: main
Folder: /docs
```

## Demo

Open `docs/index.html` or publish with GitHub Pages. The demo account is stored only in browser localStorage.

## Linux Server Install

For a full server installation guide, read:

```text
INSTALL_LINUX.md
```

The server package includes a small Flask entrypoint under `server/` so the same UI can run from a Linux host.
